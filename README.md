# Midjump (midjump.com), rebuild

A small static site. `node build.js` reads the `content` folder, checks it, and writes plain HTML pages into `dist/`, which Cloudflare publishes.

**Want to change something? Read [HOW-TO.md](HOW-TO.md).** You only ever need the `content` folder.

## Map of the repo

```
midjump2/
├── HOW-TO.md              ← click-by-click recipes (add domain, replace logo, edit text)
├── content/               ← ✏️ EVERYTHING YOU EDIT
│   ├── site.json            email, year, menu, footer wording
│   ├── landing.json         home page words, scrolling strip, FAQ
│   ├── contact.json         contact page words
│   ├── gallery.json         collection page words + category tabs
│   ├── domains/<name>/      one folder per domain: domain.json + its logo files
│   └── _new-domain-template/  copy this to start a new domain
├── public/                ← site logo, Escrow logo, fonts (rarely changes)
├── src/                   ← 🔒 code. Leave alone unless you know what you're doing
│   ├── lib/                 data.js (reads + checks content), layout.js (header/footer), util.js
│   ├── pages/               landing.js, gallery.js, contact.js, domain.js (one per page type)
│   ├── styles/site.css      all styling
│   └── js/site.js           all behaviour (menus, filter, carousel, forms)
├── build.js               ← the build script (short; ties it together)
├── wrangler.jsonc         ← Cloudflare settings (publishes dist/)
└── dist/                  ← generated by the build, not in the repo
```

## The safety net
The build checks every domain before publishing: missing logo files, duplicate names, misspelled categories, missing fields. If anything is wrong it stops with a numbered plain-English list and **the live site is not replaced**.

## Cloudflare
Build command `node build.js`, deploy command `npx wrangler deploy`. Until Cloudflare's GitHub app is installed on this repo, pushes don't build automatically: use Deployments → Create deployment.
